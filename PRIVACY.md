## 1. About LeetSync

LeetSync is a Chrome extension that helps users save LeetCode solutions to a GitHub repository of their choice and view their LeetCode progress.

This Privacy Policy explains what information LeetSync accesses, how it is used, and how users can manage it.

## 2. Information We Access and Process

To provide its features, LeetSync may process the following information:

- **GitHub account and authentication information:** OAuth access tokens, token expiration information, refresh tokens (if provided), basic account information (such as your GitHub user ID, username, avatar URL, and, if provided by GitHub, your display name or email address), and repository information.
- **LeetCode account and authentication information:** the `LEETCODE_SESSION` cookie used to authenticate your existing LeetCode session, your LeetCode user ID and username, and your solved-problem statistics by difficulty.
- **Solution information:** the LeetCode problem title, the selected programming language, and the solution source code from the LeetCode editor when you choose to synchronize a solution.
- **Extension preferences and operational data:** your selected GitHub repository and locally cached LeetCode statistics.

## 3. How We Use This Information

LeetSync uses this information only to:

- Connect your GitHub and LeetCode accounts at your request.
- Retrieve repositories you can select as a synchronization destination.
- Display your LeetCode progress in the extension.
- Upload a solution to your selected GitHub repository when you click the sync button.
- Remember your selected repository and authentication state between browser sessions.

LeetSync does not use your information for targeted advertising or sell your personal information.

Where the GDPR applies, we rely on our legitimate interest in providing the extension functionality that you choose to use (Article 6(1)(f) GDPR) and, where consent is legally required, your consent (Article 6(1)(a) GDPR). You can stop using the extension and clear local data at any time.

## 4. Local Storage and Data Transfers

LeetSync stores authentication session details, selected-repository information, and cached statistics locally in your browser using Chrome extension storage (`chrome.storage.local`). This storage should not be treated as a separately encrypted vault.

The extension communicates with GitHub and LeetCode over HTTPS to perform authentication and the features described above.

When you choose to synchronize a solution, its source code and related file information are sent to the GitHub API to create or update a file in your selected repository.

LeetSync does not operate its own backend server to store user account credentials or uploaded solutions.

## 5. Third-Party Services

LeetSync interacts with these services to perform its functionality:

- **GitHub (GitHub, Inc.):** for authentication, accessing repository information, and saving your solution files. Files saved in a **public GitHub repository may be visible to anyone**. If you choose a private repository, access is controlled by GitHub's repository permissions.
- **LeetCode:** for authentication and retrieving account information and solved-problem statistics. Your LeetCode session cookie is used for requests to LeetCode.
- **Google Chrome:** for extension APIs and local extension storage on your device.

These services process information under their own privacy policies and terms. LeetSync does not independently control information already stored in your GitHub or LeetCode accounts.

## 6. Data Retention and Deletion

Locally stored information is retained as needed to keep you signed in, remember your selected repository, and provide cached statistics.

You can clear LeetSync's locally stored information by removing the extension or clearing its extension data in your browser.

Removing LeetSync does **not** automatically delete files already uploaded to GitHub, revoke a GitHub authorization, or invalidate the LeetCode session in your browser.

You can manage uploaded files and GitHub authorizations through GitHub, and your LeetCode session through LeetCode.

## 7. Security

LeetSync uses HTTPS when communicating with GitHub and LeetCode.

Authentication information is used only for the functionality described in this policy.

No method of local storage or internet transmission can be guaranteed to be completely secure.

## 8. Your Privacy Choices and Rights

You choose whether to connect your accounts and which repository receives your solutions.

You can stop using LeetSync or clear its locally stored data at any time.

Where applicable privacy laws provide rights of access, correction, erasure, or objection, you may contact the developer at [**maciej.drywa.support@gmail.com**](mailto:maciej.drywa.support@gmail.com).

Information held by GitHub or LeetCode may need to be managed directly through those services.

Because LeetSync does not maintain its own central user database, the developer may not be able to access data stored only in your browser.

## 9. Chrome Web Store Limited Use

LeetSync's use and transfer of information obtained through Google/Chrome APIs will comply with the **Chrome Web Store User Data Policy**, including its **Limited Use** requirements.

Information is used only to provide the user-facing features described in this policy and is not sold or used for personalized advertising.
